# IKernell System - Sistema de gestión de proyectos de software.

IKernell-system es una plataforma empresarial robusta diseñada para la gestión jerárquica de proyectos de ingeniería. A diferencia de un gestor de tareas convencional, este sistema integra inteligencia de negocio para el control presupuestario proactivo y la medición de la eficiencia operativa en tiempo real.
Sistema de gestión de proyectos de software.


## Estructura
- backend/
- frontend/
- database/

## Stack Tecnológico
Lenguaje: Java 17+

Framework: Spring Boot 3.x

Seguridad: Spring Security con Stateless JWT (JSON Web Tokens)

Base de Datos: PostgreSQL / Hibernate JPA

Documentación: Swagger UI / OpenAPI 3.0

Arquitectura: Orientada a Servicios con DTOs para transferencia de datos segura.
